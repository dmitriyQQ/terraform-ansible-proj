# Proxmox LXC – управление контейнерами через Terraform

Проект предназначен для автоматизированного создания и управления LXC-контейнерами на сервере Proxmox VE с помощью подхода «инфраструктура как код» (IaC). Вместо ручного развёртывания каждого контейнера через веб-интерфейс, конфигурация описывается в файлах Terraform.

## Что делает проект

- Создаёт на указанном узле Proxmox один или несколько LXC-контейнеров из заданного шаблона ОС.
- Позволяет гибко настраивать параметры каждого контейнера: имя хоста, IP-адрес, объём ОЗУ, swap, размер диска, количество ядер CPU.
- Поддерживает шаблонизацию через переменные – можно задать общие значения по умолчанию и переопределять только то, что отличается.
- Выводит итоговую информацию (hostname и IP) по каждому созданному контейнеру.

## Как устроен

В основе лежит Terraform-конфигурация с провайдером `telmate/proxmox`. Все контейнеры описываются в виде карты в переменной `containers`, а блок ресурса использует `for_each`, чтобы создать по одному экземпляру на каждый элемент карты. Это избавляет от дублирования кода: общие настройки указываются один раз, а индивидуальные параметры берутся из карты.

## Типовой сценарий использования

1. Описать в `terraform.tfvars` нужные контейнеры.
2. Выполнить `terraform apply`.
3. Получить готовые к работе контейнеры, информацию о которых Terraform выведет на экран и сохранит в outputs.
4. При необходимости добавить новые контейнеры, просто расширив карту – существующая инфраструктура не будет затронута.
